# Imagine

Красота на Windows 11: палитра из ваших обоев, матовое стекло, две шторки в духе Android и часы, которые переезжают с экрана блокировки на рабочий стол. Вдохновлено ColorOS 17 и Material You. Работает без прав администратора.

## Что умеет

**Цвета из обоев, без пресетов.** Вы ставите обои, Imagine находит на них цвета (тот же алгоритм, что в Android 12+: квантизатор Celebi, оценка Score, цветовое пространство HCT) и строит из них схему.
- 9 стилей схемы: пастельный, яркий, выразительный, точный, контентный, радуга, фруктовый салат, нейтральный и монохром.
- 4 уровня контраста.
- Можно выбрать другой цвет с обоев, задать свой или взять пипеткой с экрана.
- Светлая или тёмная тема выбирается по яркости обоев, по расписанию или вручную.

Что перекрашивается:
- акцент Windows (кнопки, ссылки, выделение);
- панель задач, «Пуск» и заголовки окон;
- режим светлый/тёмный и прозрачность;
- подсветка клавиатуры и мыши (Dynamic Lighting);
- Windows Terminal и VS Code;
- сами окна Imagine.

**Живая палитра.**
- К вечеру цвета теплеют, ночью тема становится тёмной: по восходу и закату для ваших координат или по заданным часам.
- Пока играет музыка, акцент может браться с обложки трека.
- Обои могут меняться из папки, и палитра перестраивается под каждую картинку.

**Матовое стекло и Contour Glow.** Шторки и островок лежат на размытом акриле с оттенком палитры, по контуру светится обводка:
- однотонная;
- дуотон;
- «Аврора», которая медленно переливается.

Матовость, яркость, толщину и скругления можно настроить.

**Две шторки, как на телефоне.**
- *Слева: уведомления и состояние.* Крупные часы, батарея, «Фокус», что играет. Уведомления показываются в одном из трёх видов ColorOS 17:
  - **колода**: карточки одного приложения стопкой;
  - **капсулы**;
  - **список**.

  Есть история смахнутых, правила (скрыть, без баннера, выделить) и расписание «Фокуса».
- *Справа: быстрые настройки.*
  - 22 плитки на выбор: Wi‑Fi, Bluetooth, режим «В самолёте», тёмная тема, «Фокус», экономия заряда, микрофон, «Не засыпать», снимок экрана, пипетка, стиль палитры, другой цвет, следующие обои, буфер обмена, эмодзи и другие.
  - Порядок плиток, их размер (круглая или широкая) и число колонок настраиваются.
  - Есть яркость каждого монитора (включая внешние по DDC/CI), громкость, выбор устройства вывода и громкость по приложениям.
  - Карточка «Сейчас играет» и цвета с обоев в один клик.

**Как открыть шторки:**
- мышью: задержите курсор у верхнего края или «толкните» его вверх. Левая часть края открывает уведомления, правая — быстрые настройки; границу и мёртвые зоны по углам можно настроить;
- тачпадом: курсор у края и прокрутка двумя пальцами вниз;
- клавишами: `Win+Alt+N` (уведомления), `Win+Alt+A` (быстрые настройки), `Win+Alt+Space` (обе сразу). Сочетания меняются в настройках;
- свайпом тремя или четырьмя пальцами. Windows не отдаёт эти жесты программам, но их можно назначить на сочетание клавиш: Параметры → Bluetooth и устройства → Сенсорная панель → Расширенные жесты → «Пользовательское сочетание клавиш»;
- значком в трее: левый клик открывает быстрые настройки, правый — меню.

В полноэкранных играх и видео шторки по краю не открываются (это отключаемо).

**Часы.**
- Крупные часы на рабочем столе, встроены под значки.
- 4 раскладки: столбиком, в строку, журнальная и стрелочные.
- Настраиваются шрифт, толщина, размер, место, цвет из палитры и свечение цифр.
- После разблокировки часы «переезжают» из центра экрана на своё место.
- Экспериментально: часы Imagine можно нарисовать прямо на картинке экрана блокировки.

**Островок** у верхнего края на пару секунд показывает, что заиграло, что палитра сменилась и т. п.

**Экспорт и откат.**
- Палитру можно сохранить в CSS, JSON, схему Windows Terminal, цвета VS Code и файл темы Windows `.theme`.
- Перед каждым применением сохраняется снимок системных настроек.
- Кнопка «Вернуть всё как было до Imagine» откатывает акцент, режим, прозрачность и обои.

## Установка

Готовые сборки собирает GitHub Actions: вкладка **Actions** → последний запуск «Сборка» → раздел **Artifacts**. Когда появится тег `v*`, файлы будут и на странице **Releases**.

| Вариант | Как поставить | Что работает |
|---|---|---|
| **Обычная сборка** `Imagine-win-x64.zip` | Распаковать куда угодно и запустить `Imagine.exe`. Прав администратора не нужно. | Всё, кроме двух вещей ниже. |
| **MSIX** `Imagine-msix` | Один раз импортировать `Imagine.cer` в «Доверенные лица» локального компьютера (это требует прав администратора), затем открыть `.msix`. | Всё, включая уведомления в шторке и смену экрана блокировки. |

Windows разрешает читать уведомления и менять картинку экрана блокировки только упакованным приложениям. Поэтому в обычной сборке шторка уведомлений показывает часы, батарею и музыку, но не сами уведомления. Пакет подписан самоподписанным сертификатом из CI; когда появится настоящая подпись, импорт сертификата будет не нужен.

Запуск с параметром `--background` стартует без окна настроек, только трей, шторки и часы. Так Imagine запускается вместе с Windows.

## Ограничения Windows, которые не обойти без прав администратора и инъекций

- Кнопки внутри чужих уведомлений («Ответить», «Принять») нажать нельзя: Windows не даёт их программам. Уведомления можно читать и смахивать.
- Системные панели `Win+N` и `Win+A` не заменяются. Imagine открывает свои шторки рядом с ними.
- Системные часы экрана блокировки нельзя перекрасить. Поэтому есть экспериментальная функция, которая рисует часы на самой картинке.
- Режим «В самолёте», экономия заряда и смена устройства вывода звука работают не на всех ПК. Если не получилось, Imagine открывает нужную страницу Параметров.

## Сборка из исходников

Нужен .NET SDK 10. Для приложения нужна Windows 10 19041+ (рассчитано на Windows 11).

```powershell
dotnet test tests/Imagine.Color.Tests
dotnet test tests/Imagine.Core.Tests
dotnet publish src/Imagine.App/Imagine.App.csproj -c Release -r win-x64 -p:Platform=x64 -o out
```

Интерфейс целиком написан на C#, без XAML-файлов. Поэтому весь код, включая окна WinUI 3, компилируется и на Linux:

```bash
dotnet build src/Imagine.App/Imagine.App.csproj -r win-x64 -p:Platform=x64 \
  -p:AppxGeneratePriEnabled=false -p:WindowsAppSDKSelfContained=false
```

### Устройство

| Проект | Что внутри |
|---|---|
| `src/Imagine.Color` | Порт Material Color Utilities на C#: HCT/CAM16, тональные палитры, 9 вариантов динамической схемы с кривыми контраста, квантизаторы Wu + WSMeans (Celebi), Score, температура цвета, гармонизация. |
| `src/Imagine.Core` | Логика без Windows: анализ обоев, генерация темы, расписание и солнце, токены стекла и свечения, пружинная анимация, детектор края для шторок, раскладка плиток, группировка уведомлений, раскладка часов, настройки, снимки и откат реестра, экспорт и слияние настроек терминала и VS Code. |
| `src/Imagine.Platform.Windows` | Всё системное: реестр и WM_SETTINGCHANGE, IDesktopWallpaper, экран блокировки, радио, WASAPI, яркость (WMI и DDC/CI), медиа (GSMTC), уведомления, Dynamic Lighting, питание, низкоуровневые хуки, горячие клавиши, трей, встраивание в рабочий стол. |
| `src/Imagine.App` | Приложение WinUI 3: окно настроек, шторки, островок, часы, трей. |
| `tests/*` | 113 тестов. Цветовой движок сверяется с эталонными значениями, которые сгенерированы официальной библиотекой Google (`tools/golden/gen_golden.py`): больше 5000 проверок ролей схемы. |

## Что проверено, а что нет

- Цветовой движок и ядро покрыты тестами (113 штук). Тесты проходят на Linux и в CI на Windows.
- Весь код, включая приложение WinUI 3, компилируется без ошибок.
- Само приложение писалось без доступа к Windows, поэтому поведение окон, хуков, стекла и встраивания часов в рабочий стол ещё не проверялось вживую. Если что-то выглядит или ведёт себя не так, приложите журнал `%LocalAppData%\Imagine\imagine.log`.

Настройки хранятся в `%LocalAppData%\Imagine\settings.json` и правятся из окна Imagine или вручную.
